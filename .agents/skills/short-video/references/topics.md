# 选题

## 方向与模板

当前流水线只支持 **T1 旁白型**：旁白决定每个镜头的时长。音乐卡点（T2）、数字人唱歌（T3）、群像剧情（T4）都在后续阶段。

| 方向 | 现在怎么做 | 风格预设 | 风险 |
| --- | --- | --- | --- |
| 24 节气 | 物候三候 + 一首相关古诗 + 一个民俗 + 一句生活提醒 | `guofeng-ink` | 低 |
| 古诗 | 先读诗题和作者 → 逐句讲意象和情绪（每句 1–2 个镜头）→ 结尾一句金句 | `guofeng-ink` / `cinematic-guofeng` | 低：诗句必须逐字核对 |
| 文言文 | 原文朗读加自己写的白话译文（避开现成译本的版权） | `guofeng-ink` | 低–中 |
| 物理现象、公式、定律 | 讲解型：生活现象 → 原理 → 应用。科幻叙事型：用电影画面讲一个物理假说，比如单电子宇宙 | `physics-clean` / `epic-myth` | 中：数值和方向容易错 |
| 神话、民俗由来、龙 | 民俗由来故事，或者奇观镜头配金句 | `epic-myth` | 低 |
| 美景 + 古典美女 | 先做旁白版（诗句意境）；写实人物近景标 `photoreal`，交给 H3 | `cinematic-guofeng` | 低–中 |
| 红军长征 | 选一个真实事件，时间、地点、人数以权威党史资料为准；画面用群像、背影、远景和象征意象 | `red-epic` | **高**：事实核查要另派 subagent |
| 电视剧高光 | **改成公版原著桥段的原创演绎**：不用影视原片和演员肖像 | `cinematic-guofeng` | 高 |
| 数字人唱歌、群像嬉戏 | 暂不支持，告诉用户在后续阶段 | — | — |

## 候选来源

- **日历**：节气、传统节日、纪念日（长征、国庆、诺贝尔奖公布等）。日期一律先用 WebSearch 核实，不要凭记忆写。
- **经典库**：唐诗宋词、诗经楚辞、《古文观止》名篇、民俗由来与神话（封神、山海经、门神年画）、公版名画、物理定律。
- **热度**：用户收藏的爆款、抖音热点。可以 WebSearch 看近期热点，但不要捏造热度数据。

挑经典故事的标准：知名度高、画面感强、有情绪或冲突、属于公版或原创演绎、出处可考证。

## 选题卡格式

每张卡回答「这条为什么值得做」：

```markdown
### 选题 A：<标题候选，20 字以内，带钩子>
- 方向 / 模板：古诗 · T1 旁白（约 60 秒，9:16，guofeng-ink）
- 钩子（前 3 秒）：<设问、反常识或金句>
- 故事线：起 … → 承 … → 转 … → 合 …（结尾金句或互动提问）
- 经典素材：《山行》杜牧（原文待核对）
- 最出片的 3 个镜头：…
- 为什么能火：时令 / 情绪 / 反常识 / 系列化
- 风险与成本：写实人物？红色题材？大约 14 个镜头，约 7 万 AFP（默认 Seedance 2.5）
```

可以给每张卡打个分作参考：时令性 × 0.3 + 热度 × 0.25 + 新颖度 × 0.2 + 可视化潜力 × 0.15 − 风险 × 0.1。

## 标题公式（来自用户收藏的样片）

- 「系列名 | 诗句」：种田·群像 | 山中何事？松花酿酒
- 「风格标签 + 诗句」：中式意境 巨物美学 古道西风瘦马
- 对仗金句：龙藏渊薮，风待云生
- 设问 / 反常识：古人为什么说霜降是「秋之终」？

建议做成系列（「AI 重现节气」「诗里的中国」），同一系列固定风格和角色。

## 爆款观察（24 条样本，只作参考）

- 点赞最高的是情绪型内容：歌曲具象化、龙配金句、民俗传说、金箔画美人。
- 知识型内容点赞偏低，但可能更涨粉、收藏更多。
- 大多是 16:9 电影感；人物多用背影、剪影、远景，靠构图取胜。
