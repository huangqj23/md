# 事实核查

剧本导入前做完，结果写进 `check`：

```json
"check": {"ok": false, "issues": [{"shot": "s03", "problem": "哪里错了", "fix": "怎么改"}], "checker": "Claude"}
```

能改的问题直接改掉剧本。改完的问题可以留在 `issues` 里并加上 `"resolved": true`，分镜表会标「已处理」。

## 清单

| 类别 | 核对什么 | 去哪查 |
| --- | --- | --- |
| 古诗文 | 原文一字不差（标点可以不同）、诗题、作者、朝代；旁白里引用的句子能在 `source.text` 里找到 | WebSearch / WebFetch 找古诗文网、维基文库，至少对照两个来源；拿不准就换一首 |
| 节气 | 当年的交节日期、物候三候、相关民俗的出处 | 用 WebSearch 查当年的日期，不凭记忆 |
| 民俗与神话 | 由来故事有没有可靠出处；不把传说写成史实（用「相传」「民间说法」） | 百科、地方志类来源 |
| 历史 | 时间、地点、人物、人数、经过 | 权威史料；红色题材以官方党史资料为准 |
| 科学 | 数值、单位、方向、因果；画面会不会画错（比如把太阳画进彩虹中央） | 教材、百科；数值写到旁白前再算一遍 |
| 数字口径 | 「涨了」和「涨到」、倍数、比例能不能算得出来 | 自己验算 |

## 需要独立复核的题材

**物理、历史、红色题材**要另派一个 subagent 复核：

- 只给它剧本文本（标题、引用、每镜旁白），让它逐条列出确有错误的地方，不评价文风。
- 不让它看你的推理过程，避免它跟着你的思路走。

## 红色题材的边界

- 尊重史实，不戏说，不加虚构细节。
- 不生成领袖和英烈的写实形象，画面只用群像、背影、远景和象征意象（红旗、雪山、金光）。
- 成片最后交给用户人工终审。
