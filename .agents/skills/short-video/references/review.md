# 质检

查看方式：用 `ai-video sheet <id> --what keyframes|clips|final` 生成联系表，再用 Read 工具看图。要看单张原图，Read `data/projects/<id>/keyframes/s03.png`。

## 角色参考图

- 全身图和大头照是不是同一个人；服饰颜色和 `look` 是否一致。
- 背景干净，没有多余的人和道具，没有文字。

## 关键帧

- **构图**：主体清楚，景别和分镜要求一致，相邻镜头的景别有变化。
- **一致性**：同一角色的脸、发型、服饰前后一致；`prev` 镜头和上一镜的场景、光线连贯。
- **崩坏**：手指、肢体、五官有没有畸形；建筑透视是否合理。
- **文字**：画面里不该有字；如果出现乱码，在 `image_prompt` 里改写，或者删掉相关元素。
- **画风**：整条片子风格统一。
- **写实人脸**：有清晰写实人脸、但 `photoreal` 是 `false` 的镜头，要么改成 `true`（走 H3），要么改成背影或远景。
- **贴题**：画面和这句旁白对得上。

不合格的处理：改 `image_prompt`、`refs` 或 `look`，然后 `ai-video script <id> <文件>`；或者直接 `make <id> --redo s03`。同一个镜头连续三次不行，就换个画面思路，不要硬磨。

## 视频片段

- 运动自然，没有突然变形、闪烁、穿模或主体消失。
- 动作和 `video_prompt` 一致，运镜只有一种。
- 没有自动生成的字幕、Logo 或水印。
- 草稿阶段主要看节奏和动作，画质以正式版为准。

## 成片

- **节奏**：开头 3 秒抓不抓人；有没有拖沓的镜头。
- **字幕**：和旁白一致，没有错别字，没有残留的 `<long pause>` 之类标签，不压画面主体。
- **事实**：诗句、数字、史实和核查结果一致。
- **合规**：右上角有「AI生成」角标；红色题材没有领袖和英烈的写实正脸。
- **封面**：`out/cover.png` 能不能用；封面大字是否醒目。
- **发布信息**：`out/publish.md` 的标题、话题和引用出处。

## 独立审片（subagent）

派一个没参与制作的 subagent，只给它三样东西：

- `sheets/final.jpg`
- `out/final.srt`
- `out/publish.md`

提示词示例：

> 你是短视频的终审编辑。只根据给你的成片抽帧、字幕和发布信息挑问题：画面崩坏、前后不一致、字幕错字或和画面不符、事实错误、合规风险（AI 标识、红色题材、肖像）。每个问题写出时间点或镜头、现象、建议改法；没有问题就说没有。不要评价文风。

拿到结果后，逐条判断是否采纳。要改的，回到对应阶段重做。
